# vim-steve-theme

A custom color scheme for Vim.

## Installation

Using [vim-plug](https://github.com/junegunn/vim-plug):

```vim
Plug 'StevenTomer/vim-steve-theme'
```

## Usage

Put this in your .vimrc:

```vim
set termguicolors " Optional, if your theme requires true color
colorscheme steve_theme
```
